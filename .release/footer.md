## Installation

**HACS → ⋮ → Custom repositories** → `stefgo/ha-crowdsec-integration`, category **Integration** →
*Add*. Then install "CrowdSec" and restart Home Assistant.

Manually: copy `custom_components/crowdsec/` from the attached zip to
`<config>/custom_components/` and restart Home Assistant.

Full documentation is in the [README](https://github.com/stefgo/ha-crowdsec-integration#readme).
